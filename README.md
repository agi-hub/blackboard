# 敲黑板

AI 备课授课一体化的黑板教学原型：粘贴文本或拍照上传图片素材，AI 备成多页粉笔板书（图示 + 彩色重点 + 口语化讲稿），教师配音逐块讲解、板书同步书写、讲到哪句讲义记哪句；支持指行提问、手写涂鸦、课程存档。

## 运行环境

- **Bun ≥ 1.0**（唯一的运行时依赖，无任何 npm 包依赖）
  - 安装：`curl -fsSL https://bun.sh/install | bash`
- 现代浏览器（Chrome / Edge / Safari）

## 快速开始

```bash
cd ~/blackboard
bun server.ts        # 或 bun run start；默认 http://127.0.0.1:8918
```

打开 <http://127.0.0.1:8918>。首次使用点「⚙ 设置」配置：

| 设置项 | 说明 |
|---|---|
| 模型服务 | OpenAI 兼容 chat/completions 的 baseUrl + API Key + 文本模型（板书排版）+ 视觉模型（图片素材识别，默认 glm-5.3-flash） |
| 配音 TTS | SiliconFlow 兼容 /audio/speech 的 baseUrl + API Key + 模型 + 音色（8 款预置男女声） |
| 外观 | 板书字体（楷体/行楷/宋体/黑体/圆体/仿宋）+ 字体磨砂感（粉笔颗粒强度五档） |

配置持久化在本机 `config.json`（权限 600，已被 gitignore）。也可复制 `config.example.json` 手工填写。

> **密钥安全**：`config.json` 含真实 API Key，**永远不要提交或推送**。本仓库的 `pre-push` 钩子（`.git/hooks/pre-push`）会在推送前扫描所有待推送提交的新增行，命中 API 密钥格式或触及 `config.json` 即拒绝推送。克隆后如需启用同一防线，可执行：`cp .githooks/pre-push.example .git/hooks/pre-push && chmod +x .git/hooks/pre-push`。

## 功能总览

### 备课（✎ 输入素材 → 🚀 开始讲课）
- 粘贴文章/笔记/Markdown，或 📷 **上传图像**（拍照/相册）→ AI 去水提纯。图片走视觉模型（`visionModel`），题目图片自动附解题步骤与答案；文本+图片可混用，内容融合成一套板书。**贪心流式排版**：块按阅读顺序跨区域流动、图宽按剩余高度换算并保证图内文字 ≥20px、7 档渐进收缩、总结条可牺牲——任何内容量零重叠
- 多页分页，◀▶ / ←→ 翻页，**播完一页 3 秒后自动连播下一页**
- 8 色粉笔色板（黄=重点/橙=警示/粉=易错/蓝=数据/绿=收益/紫=注释），重点词行内彩色加粗
- **SVG 图示**：模型直接输出粉笔线框风 SVG，两段式生成（无图自动补画），渲染前安全过滤 + 黑底适配（无黑底填充）+ 图内文字与板书同字体

### 授课（🔊 讲解 / ↻ 重播）
- 教师节奏：**快写完一块 → 开口讲这块 → 讲完再写下一块**；无配音时按 5 字/秒阅读节奏逐行停顿
- 讲稿口语化（那么/然后/你看/对吧/比如说…），TTS 转读规则：普通文本 `-` 读「杠」，`math{公式}` 段直读
- **讲稿标记**：`circle{词}` / `underline{词}` —— 讲到该词时在板书上同步画圈/划线（词位 × 语音时长定时）
- **讲义区**（右侧）：老师口述实时记录，念一句多一句，颜色跟随板书块
- 跳过：单击黑板立即定格 + 停音

### 提问（🙋 我要问问题）
- 进入提问模式（问号光标）→ 指着黑板上某行点击 → 该行 + 整板上下文发给 AI → 解答写在**右侧独立小黑板**（不与板书混排），快写 + 配音，新问题覆盖前一问

### 板书工具（左侧磁吸粉笔槽）
- 7 色粉笔（木条轨道 + 磁铁贴片造型）、三档粗细、板擦、撤销、清屏
- 粉笔笔刷：飞白颗粒 + 压感；石膏磨砂字粒（按字形掩码打孔，强度可调）

### 课程存档
- 💾 **保存课程**：AI 备课输出存为纯文本 JSON（板书+讲稿+SVG+标记，~4KB/课，不含音频图像）
- 📂 **加载课程**：重建图示、按当前音色重新合成语音、自动开讲——换音色重放同节课

### 其它
- 📷 截屏（3200×2000 高清 PNG）、⛶ 全屏（双击黑板也可）、◐ 黑板/绿板主题

## 架构

```
public/            前端（纯原生 JS，零框架零构建）
  index.html         页面骨架：顶栏/粉笔槽/黑板/抽屉/解答面板/讲义区/设置
  style.css          黑板、木框、磁吸粉笔槽样式
  app.js             粉笔引擎 + 排版器 + 讲解时间线（逻辑坐标 1600×1000，三层 canvas）
server.ts          Bun 代理：静态托管 + LLM/TTS 转发（密钥不出本机）+ 令牌桶限流 + 配置管理
config.json        运行时配置（gitignore）
```

### 板书协议（AI 输出约束）

```json
{"pages":[{"title":{...,"say":"口播讲稿"},"regions":[...],
  "blocks":[{"region","text","say","svg","emphasis":[],"fontSize","color"}],
  "summary":{...}}]}
```

- `say` 讲稿嵌标记：`circle{词}`/`underline{词}`（板书动作）、`math{公式}`（TTS 直读）
- 服务端字段容错 + 坐标钳制；前端确定性排版（区域只是语义分组，位置由排版器计算）

## API

| 端点 | 说明 |
|---|---|
| `POST /api/text2board` | `{text, canvasW, canvasH}` → 多页板书 JSON（无图自动补画） |
| `POST /api/ask` | `{line, context, x, y}` → 指行解释文本 |
| `POST /api/tts` | `{text, voice}` → `{audio: dataURL}`（mp3） |
| `GET/POST /api/config` | 读（密钥打码）/ 写配置 |

限流默认 10 次/分钟（令牌桶）。

## 常见问题

- **没声音**：看页面 toast 提示——TTS 失败会告知原因（余额/Key），自动切无声模式
- **图内文字小**：已保证有效字号 ≥20px（受区域宽度物理限制的极端情况除外）
- **端口占用**：`PORT=9000 bun server.ts`

## 在 iPad / iPhone 上使用（PWA）

1. Mac 与 iPad/手机连接**同一 WiFi**
2. 设备 Safari 打启动日志里的局域网地址（形如 `http://192.168.1.9:8918`）
3. Safari 分享菜单 →「**加入主屏幕**」→ 获得 App 图标，点开即全屏运行（无浏览器栏）
4. Apple Pencil 直接书写（已支持压感）；双指/双击等触屏交互与桌面一致

> 注意：此方式需要 Mac 上的 `bun server.ts` 保持运行。服务当前**无鉴权**，仅限家庭/教室局域网使用；如需公网访问，须先加访问令牌。若要做成 App Store 上的独立 App，用 Capacitor 把 `public/` 打包为 iOS 壳即可（需 Apple 开发者账号）。

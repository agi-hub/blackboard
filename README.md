# 黑板 Blackboard · MVP 原型

参考《「黑板」产品 MVP 最简技术方案》落地的可运行原型：AI 把冗余文本排版成黑板板书，用户自由手写，AI 看得懂手写内容并在同屏作答。

## 快速开始

```bash
cd ~/blackboard
bun server.ts          # 启动，默认 http://127.0.0.1:8918
```

浏览器打开 <http://127.0.0.1:8918>。AI 功能需要 `config.json` 里有可用的 API Key（首次可点页面右上「⚙ 设置」填写，密钥只落在本机 `config.json`，权限 600）。

## 功能（对应方案 §3 MVP 清单）

| 功能 | 说明 |
|---|---|
| 文本转板书（多页） | 粘贴文章/笔记/Markdown → AI 去水提纯 → 自动分页（每页一个主题、大字号 26~52），◀▶ 或 ←/→ 翻页，每页首次观看都有逐行书写动效（约 40ms/字 + 行间停顿） |
| 重点标记 | AI 自动圈选（circle）/下划线（underline）关键词；粉笔色板区分语义：黄=重点、粉=警示、蓝=数据、绿=收益 |
| 粉笔手写 | 多色粉笔（飞白颗粒笔刷）、压感、粗细三档、橡皮擦、撤销（⌘/Ctrl+Z）、清屏（当前页）；手写按页隔离 |
| AI 解答 | 一键整屏截图 → 多模态模型识别手写/圈注/草图 → 在当前页空白区粉笔作答（含重点圈选） |
| 导出 / 主题 | 当前页 3200×2000 高清 PNG；经典黑板 / 护眼绿板 |

## 架构（对应方案 §1.2 三层）

```
public/            前端画布层
  index.html         页面骨架（工具栏/黑板/抽屉/设置）
  style.css          黑板、木框、粉笔槽样式
  app.js             粉笔引擎 + AI 交互（逻辑坐标 1600x1000，三层 canvas）
server.ts          转发层：静态托管 + LLM 代理 + 令牌桶限流 + 配置管理（密钥不出本机）
config.json        运行时配置（gitignore，含密钥）；模板见 config.example.json
```

### 板书 JSON 协议（方案 §2.2 扩展：多页 + 重点标记）

LLM 被约束为只输出 `{"pages":[{title, blocks[], summary}]}`，每块带坐标/字号/颜色与可选 `emphasis:[{text, style: circle|underline, color}]`；服务端做字段容错与坐标钳制，前端按逻辑坐标 1600×1000 等比渲染。重点词由前端在书写的行内定位后用粉笔圈/下划线补画（写完一行圈一行，模拟老师行为）。

### AI 后端

默认智谱 OpenAI 兼容端点；`glm-5.3`（禁深度思考，排版 ~10-25s、schema 稳定）+ `glm-5.3-flash`（唯一多模态，识图作答，思考链约 1-2 分钟）。任何 OpenAI 兼容服务（如本机 LM Studio `http://127.0.0.1:1234/v1`）都可在设置中替换；「禁用深度思考」对不支持的端点会被忽略。

## API

| 端点 | 说明 |
|---|---|
| `POST /api/text2board` | `{text, canvasW, canvasH}` → 板书 JSON |
| `POST /api/answer` | `{image: dataURL, canvasW, canvasH, note?}` → 板书 JSON |
| `GET/POST /api/config` | 读（密钥打码）/ 写配置 |

限流默认 10 次/分钟（令牌桶），可在设置中调整。

## 已知边界（方案 §5.2 一致）

- 超长文本偶发布局拥挤，依赖 LLM 排序精度
- 视觉模型思考链较长，AI 解答约 1~2 分钟（有 loading 遮罩提示）
- 极潦草手写识别率有限

## 验证记录（2026-09-02）

### 第二轮（多页 + 重点标记 + 逐行动画）

- 会议纪要示例 → 自动分为 **3 页**，每页主题独立，字号 28~46（标题 46）
- 重点标记：circle「留存率仅 23%」「透明度」、underline「看不懂」「重试成本高」均渲染；颜色分布 黄 8222 / 蓝 3506 / 白 9123 / 粉 1381 px
- 逐行书写动效：150 字页面 ~40ms/字 + 行间停顿，5.6s 写完 104 字（采样单调递增，非一次性）
- 翻页 ◀▶ 与 ←/→ 键盘均可用；每页首次观看重新播放书写动效；手写按页隔离（p1=0/p2=1 笔）
- 画布等比 1600:1000（sx=sy），华文行楷渲染，字形不再压扁、基线平稳

### 第一轮（MVP 闭环）

- 文本转板书：会议纪要示例 → 6 块标准板书结构，22.5s
- 手写 `9×7=?` + 粉色圈注 → AI 识别并作答 `63`（含口诀），落位空白区
- 撤销/橡皮像素级验证一致；导出 3200×2000 PNG；主题切换背景色变化
